# Speed-Go (SpeedGo)

现代化、轻量化、高性能网络测速系统。

## 特性亮点

- **Go 核心架构**：基于 Go 语言的高性能流量引擎，单连接内存控制在 32KB ~ 64KB 以内，支持万兆（10Gbps+）带宽测速。
- **极低内存占用**：前端采用 Fetch Streams（`ReadableStream`）随读随销，彻底解决客户端内存暴涨问题。
- **连续 Ping 与网络稳定性监控**：基于 WebSocket 全双工长连接，实时高频测量延迟、抖动（Jitter）、最差延迟与断网重连次数，并提供可视化图表。
- **离线 IP 库与脱敏**：内置离线地理与 ISP 识别库，零外部 API 依赖；公开测试记录敏感 IP 自动脱敏。
- **现代化 React 前端**：采用 Tailwind CSS + shadcn/ui 大圆角设计、平滑渐变 SVG 环形进度仪表盘。
- **多语言与智能感知**：支持根据用户 IP 自动推荐语言，支持手动切换与持久化记录。
- **交互式 CLI 测速**：支持通过 `curl -sL https://.../cli | bash` 一键终端交互式测速。
- **轻量 SQLite 存储**：单机 WAL 模式并发持久化测速记录。
